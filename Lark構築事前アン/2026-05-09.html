主な議題と内容

アンケートの目的
  • 商談前の情報取得による成約率アップ
  • リードタイムの短縮が主目的
  • Larkフォームに実装予定
Q1：基本情報（必須項目）
  • お名前・会社名/団体名・メールアドレス（必須）
  • 電話番号（任意）
Q2：従業員規模（単一選択）
  • 選択肢：1〜10名 / 11〜50名 / 51〜200名 / 201〜1,000名 / 1,001名以上
Q3：Larkをどのような「存在」に育てたいか（単一選択）
  • ①業務のデジタル化フェーズ（目安：50〜150万円）
  • ②業務プロセスの最適化フェーズ（目安：150〜400万円）
  • ③経営の可視化・データドリブン化フェーズ（目安：400万円〜）
  • ④課題整理からの戦略相談（予算目安なし）
  • 回答結果によりご提案内容と投資規模が変わる設計
Q4：課題を感じている領域（複数選択）
  • 10カテゴリから複数選択可
  • 主な選択肢：バックオフィス業務 / 営業・顧客管理 / コミュニティ・スクール運営 / 業務改善・見える化 / タスク・プロジェクト管理 / 人材育成・オンボーディング / 情報共有・コミュニケーション / セキュリティ・アクセス管理 / 外部システム連携・取引先対応 / その他
Q5：特に解決したい悩み（最大3つ選択）
  • Q4の回答に応じてLark表示条件で選択肢を出し分け
  • カテゴリ別に具体的な悩みを最大3つまで選択可
  • 各カテゴリ6〜8個程度の具体的選択肢を用意
  • 代表例：経費精算のスマホ完結 / 営業パイプラインの可視化 / 申込〜入金の一元管理 / マニュアル整備・属人化解消 など
📝

その他メモ

  • 本資料はあくまで「叩き台」であり、内容は今後変更・調整される可能性あり
  • Q3の投資目安金額はリード層のセグメント分けと提案準備に活用する想定
  • Q5の選択肢は全10カテゴリ×複数項目と細かく設計されており、バックオフィス・営業・スクール運営・組織改善など幅広い業種・職種をカバーしている
  • 文字起こしは音声変換ではなくフォーム設計の構造化テキストであるため、発言者・日時・参加者情報は含まれていない
